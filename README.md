# reinfolib-tools

国土交通省の不動産情報ライブラリが提供する API（不動産価格（取引価格・成約価格）情報取得 API、XIT001）から不動産の取引価格情報を取得して、都道府県 × 市区町村 × 物件種別 × 四半期の件数と価格中央値に集計し、グラフと通知文を作る道具です。成約価格情報については、取引価格情報と混ぜずに集計する専用のスクリプトが別にあります。Python の標準ライブラリだけで動きます。データの取得には API キー（無料・申請制）が必要です。

## ファイル

- `reinfolib_collect.py`：都道府県と期間を指定して XIT001 を呼び、返ってきた JSON をファイルに保存します（API の応答が辞書形式の場合は、配列に包んでから保存します）。ファイル名には価格情報の種別が付き、取引価格情報は `_pc01`、成約価格情報は `_pc02` になります
- `reinfolib_aggregate.py`：保存した JSON 群から、都道府県 × 市区町村 × 物件種別 × 四半期ごとの件数と、取引価格（総額）と平方メートル単価の中央値を CSV に集計します
- `reinfolib_report.py`：集計 CSV から、取引件数が最多の市区町村について、四半期ごとの件数を主要な物件種別（上位3種）で積み上げた棒グラフの HTML と、通知文を作ります。通知文の件数は上位3種の合計で、件数と種別ごとの平方メートル単価中央値を、対象市区町村のデータにある1つ前の四半期と比べます。件数の差は、1つ前の四半期がある場合だけ出します。直近四半期の単価が無い種別は載せず、単価の差は、1つ前の四半期のその種別の単価中央値が空欄か0の場合は出しません。環境変数 `DISCORD_WEBHOOK_URL` が設定されていれば、通知文を Discord にも送ります（集計が空の場合は、通知文はファイルに書くだけで送信しません）
- `reinfolib_aggregate_pc02.py`：成約価格情報（`_pc02` のファイル）だけを読んで、取引価格情報と同じ集計キーで件数と成約価格（総額）の中央値を CSV に集計します
- `reinfolib_report_pc02.py`：成約価格の集計 CSV から、成約件数が最多の市区町村について、四半期ごとの成約件数を、件数の多い上位3種の物件種別で積み上げた棒グラフの HTML と、通知文を作ります。通知文は、その市区町村で件数の多い上位3種について、直近四半期の件数と種別ごとの成約価格中央値を、その市区町村のデータにある前の四半期と比べます。直近四半期に成約価格（総額）の中央値が無い種別は載せず、前の四半期が無い場合は件数と価格の差を出さず、前の四半期の中央値が空欄か0の場合は価格の差を出しません。取引価格情報の集計 CSV を第2引数で渡すと、比べる節に重なったグループの中央値同士の比較結果が入ります。数値の比較が入るのは、成約・取引の両側に0でない総額中央値があり、取引価格側の中央値が正で比を作れるグループがある場合だけです（第2引数に存在しないファイルのパスを指定した場合は、重なりが0件と表示されます。成約価格の集計が空の場合は、比べる節自体ができません）。通知文はファイルに書くだけで、外部には送信しません
- `sample/xit001_sample.json`：API キーが無くても集計とレポートの動きを試せる、公式マニュアルの出力項目に沿ったサンプルデータです

## API キーの取得

キーは不動産情報ライブラリの API 利用申請ページ（https://www.reinfolib.mlit.go.jp/api/request/）から申請します。氏名、メールアドレス、利用目的などを登録し、審査が通るとキーがメールで届きます。料金はかかりません。

取得したキーは環境変数 `REINFOLIB_API_KEY` に設定して使います。キー自体をファイルに書く必要はありません。

```sh
export REINFOLIB_API_KEY="取得したキー"
```

## 使い方

```sh
# 1. 取引価格情報を取得する（既定は東京都・2024〜2025年・取引価格情報のみ）
python3 reinfolib_collect.py data/

# 都道府県（--area、カンマ区切りで複数可）と期間、価格情報の種別を指定する場合
python3 reinfolib_collect.py data/ --area 13,14 --from-year 2023 --to-year 2025 --price-classification 01
# --price-classification: 01=取引価格情報のみ、02=成約価格情報のみ、all=両方（既定は 01）

# 2. 集計する
python3 reinfolib_aggregate.py data/ reinfolib_quarterly_summary.csv

# 3. グラフと通知文を作る
python3 reinfolib_report.py reinfolib_quarterly_summary.csv reinfolib_report.html reinfolib_notify.txt
```

成約価格情報を分けて集計する場合は、取得先のディレクトリを分けてください。

```sh
# 4. 成約価格情報を、別のディレクトリに取得する
python3 reinfolib_collect.py data_pc02/ --area 13 --from-year 2021 --to-year 2025 --price-classification 02

# 5. 成約価格情報だけを集計する（_pc02 のファイルだけを読みます）
python3 reinfolib_aggregate_pc02.py data_pc02/ reinfolib_pc02_quarterly_summary.csv

# 6. グラフと通知文を作る（第2引数は、手順2の取引価格情報の集計CSVです。
#     第2引数に存在しないファイルのパスを指定した場合は重なりは0件と表示され、成約価格の集計が空の場合は比較の節はできません）
python3 reinfolib_report_pc02.py reinfolib_pc02_quarterly_summary.csv reinfolib_quarterly_summary.csv reinfolib_pc02_report.html reinfolib_pc02_notify.txt
```

API キーが無い状態で動きだけ見たい場合は、サンプルデータで 2 と 3 を試せます。

```sh
python3 reinfolib_aggregate.py sample/ reinfolib_quarterly_summary.csv
python3 reinfolib_report.py reinfolib_quarterly_summary.csv reinfolib_report.html reinfolib_notify.txt
```

## 集計の読み方

取引価格情報は、実際の取引を対象に行われたアンケート調査に基づく価格です。売出時の希望価格ではありません。成約価格情報は、指定流通機構（レインズ）に登録された物件の成約事例に基づく価格です。`reinfolib_aggregate.py` の集計では両者を区別せず、指定したディレクトリにある `xit001_*.json` の全体を対象に数えるので、価格情報の種別ごとに集計したい場合は、上の手順のように取得先のディレクトリを分けてください。

なお、`--price-classification all` で取得したファイル（ファイル名は `_pcall`）は、成約価格専用の集計（`reinfolib_aggregate_pc02.py`）では読まれません。成約価格を分けて集計する場合は、`02` で取得してください。

集計は、取引時点（例:「2025年第1四半期」）を四半期にそろえ、都道府県・市区町村・物件種別（宅地（土地）、中古マンション等、など）ごとに件数を数え、取引価格の総額と平方メートル単価の中央値を出します。価格が入っていない、または数値として読めないレコードは、件数には数えますが中央値の計算からは除きます。

取得できる期間は、取引価格情報が2005年第3四半期以降、成約価格情報が2021年以降です。

### 成約価格情報の集計について

XIT001 の出力項目には平方メートル単価（UnitPrice）もありますが、当方で取得した2021〜2025年の成約価格情報の全627,749件では、値が入っているレコードは0件でした。`reinfolib_aggregate_pc02.py` は、単価が入っているレコードがあればその中央値を出す作りで、単価の値が1件も無かったので、CSV の単価の列は空になっています。この範囲では、価格の指標は成約価格（総額）の中央値だけです。物件種別も取引価格情報と違って「中古マンション等」と「宅地（土地と建物）」の2種だけでした。

レポートの比較の節は、成約価格情報と取引価格情報で同じ「都道府県 × 市区町村 × 種別 × 四半期」のグループ同士の、総額中央値を比べたものです。重なりに数えるのは、両側に0でない総額中央値があるグループだけで、比は取引価格側の中央値が正のグループについて作ります。同じ物件同士の比較ではないので、成約 ÷ 取引の比は値引き率ではありません。当方のデータでは、重なるグループが10,205件あり、比の中央値は1.014でした。種別別では、宅地（土地と建物）が0.980（6,331グループ）、中古マンション等が1.083（3,874グループ）です。重なりは、比較に使った当方の取引価格情報の集計（2024〜2025年分）の中だけにあります。

当方で取得した2021〜2025年・全国47都道府県の成約価格情報627,749件を集計すると、28,039グループになりました。成約件数が最多の市区町村は東京都世田谷区で、直近四半期（2025年第4四半期）は569件、成約価格の中央値は中古マンション等が6,700万円、宅地（土地と建物）が9,300万円でした。

## データの出典と利用条件

出典: 国土交通省 不動産情報ライブラリ（https://www.reinfolib.mlit.go.jp/）
「不動産取引価格情報」「成約価格情報」（国土交通省）をもとに集計・加工して作成

データの利用条件は、公共データ利用規約（第1.0版）に準拠します。利用の際は出典の記載が必要です。編集・加工して利用する場合は、出典とは別に、もとのコンテンツの名称と、編集・加工した旨を記載してください。この道具が出力するレポートと通知文には、出典と加工の明記を分けて表示しています。出典はどちらも『出典: 国土交通省 不動産情報ライブラリ（https://www.reinfolib.mlit.go.jp/）』で、加工の明記は、取引価格情報の集計では『「不動産取引価格情報」（国土交通省）をもとに集計・加工して作成』、成約価格情報の集計では『「成約価格情報」（国土交通省）をもとに集計・加工して作成』です。成約価格情報のレポートで取引価格情報の集計 CSV を読み込み、そこにデータ行があった場合は、加工の明記は『「成約価格情報」「不動産取引価格情報」（国土交通省）をもとに集計・加工して作成』と、使った両方のコンテンツを挙げます（重なりが0件の場合も同じです。ヘッダーだけの CSV では併記されません）。

API の利用には API 利用規約が別にあります。本 API 機能を利用したサービスを提供する場合は、利用規約第7条のクレジット表示を、利用者が参照できる場所に表示する必要があります。この道具が作るレポート HTML には、クレジット表示の文言を末尾に入れています。また、「不動産情報ライブラリ」という名称は、国土交通省が認めた場合を除き、製品やサービスの名前に使うことはできません（不動産情報ライブラリ利用規約 第3条（7））。
